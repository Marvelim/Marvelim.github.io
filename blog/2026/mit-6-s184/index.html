Flow and Diffusion Models

Flow Models

Preliminaries: ODE

ODE: 一个 ODE 被一个向量场 $u$ 定义：

\[u: \mathbb{R}^d \times[0,1] \rightarrow \mathbb{R}^d, \quad(x, t) \mapsto u_t(x),\]

该 ODE 的解是一条轨迹 $X$: \(X:[0,1] \rightarrow \mathbb{R}^d, \quad t \mapsto X_t\)

ODE 可以看作是对轨迹的限制（在每个时刻，$X_t$ 的移动必须符合 $u_t(X_t)$ 定义的速度向量方向）. 即

\begin{equation} \label{eq:ode} \begin{aligned} \frac{\mathrm{d}}{\mathrm{~d} t} X_t & =u_t\left(X_t\right)
X_0 & =x_0 \end{aligned} \end{equation}

一个流 $\psi$ 是从指定的一点 $x_0$ 到上述轨迹的映射，可以看作是一个可以直接吐出来“轨迹是什么”的函数：

\[\begin{aligned} \psi : \mathbb{R}^d \times[0,1] \mapsto \mathbb{R}^d& , \quad (x_0,t) \mapsto \psi_t(x_0) \\ \frac{\mathrm{d}}{\mathrm{~d} t} \psi_t(x_0) &= u_t(\psi_t(x_0)) \\ \psi_0(x_0) &= x_0 \end{aligned}\]

总结一下：ODE $u$ 的解是一条路径 $X$, 而 $\psi$ 是 $x_0 \to X$ 的 mapping. 正如下图所示，$\psi$ 的移动实际上符合 $u_t$:

解 ODE: 多数情况下 $\psi_t$ 是没有封闭形式的，我们只能把这条轨迹模拟出来，例如对式 \eqref{eq:ode} 使用 Euler 法

\[X_{t + h} = X_t + hu_t(X_t)\]

Flow Model 是什么

一个流模型实际是一个神经网络向量场 $u_t^{\theta}$, 满足当 $X_0 \sim p_{\text{init}}$ 时，按上述向量场采样得到的 $X_1 \sim p_{\text{data}}$. 若能构造出这样的向量场，从源分布中采样一个 $X_0$ 后模拟得到 $X_1$ 即可完成从 $p_{\text{data}}$ 中采样的目的。

Diffusion Model

Preliminaries: SDE

SDE 中引入的随机性可以通过布朗运动来解释：一个布朗运动 $W = (W_t)_{0 \leq t \leq 1}$ 是一个随机过程，满足：

  1. $W_0 = 0$, $W_t$ 关于 $t$ 连续；

  2. 对任何 $s<t$, $W_t - W_s \sim \mathcal{N}(0, (t - s)I_d)$;

  3. 对任何分割 $0 \leq t_0 < t_1 < \ldots < t_n \leq 1$, $W_{t_1 - t_0}, \ldots, W_{t_n - t_{n-1}}$ 是独立的随机变量。

布朗运动又被叫做维纳过程。如果按下面的流程进行离散模拟，那么就可以“近似“为一个满足上述条件的布朗运动：

\[W_{t + h} = W_t + \sqrt {h} \epsilon_t, \epsilon_t \sim \mathcal{N}(0, I_d)\]

ODE $\to$ SDE 如果要在 ODE 中引入上述随机性，首先不能求导了，需要一个离散的解释。对 \eqref{eq:ode} 可以改写为

\[\frac{1}{h}(X_{t + h} - X_t) =u_t\left(X_t\right) + R_t(h)\]

只需要多出来的一个项可以忽略：$R_t(h) \to 0 (h \to 0)$. 这样 reformat 可以得到

\[X_{t + h} = X_t + hu_t(X_t) + hR_t(h)\]

在这个表达式中添加布朗运动后：

\[X_{t+h}=X_t+\underbrace{h u_t\left(X_t\right)}_{\text {deterministic }}+\sigma_t \underbrace{\left(W_{t+h}-W_t\right)}_{\text {stochastic }}+\underbrace{h R_t(h)}_{\text {error term }}\]

其中 $\sigma_t$ 控制了随机项的强度。

解 SDE: 上述过程实际上是用 Euler-Maruyama Method 来解的，人话是利用 $W_{t+h} - W_t$ 服从正态分布的性质：

\[X_{t+h}=X_t+h u_t\left(X_t\right)+\sqrt{h} \sigma_t \epsilon_t, \quad \epsilon_t \sim \mathcal{N}\left(0, I_d\right)\]

Diffusion Model 是什么

一个扩散模型实际上就是 $u_t^{\theta}$ 和 noise schedule $\sigma_t$ 的组合（sample 过程如上），类比 Flow Model.

Flow Matching

这一章主要聚焦于，该如何训练 Flow Model $u_t^{\theta}$. 这里有一点小巧思：就是 $u_t^{\theta}$ 的作用，实际上是一个分布上从 $p_{\text{init}}$ 到 $p_{\text{data}}$ 的 “warping” 过程。如果能够定义出中间分布，也就是 $t$ 时刻的概率分布，或许对 $u$ 的训练是一件好事。

概率路径

为此，我们定义概率路径。对数据点 $z \in \mathbb{R}^{d}$, 可以想象的是，可以构造出一条条件概率路径 $p_t(x \mid z)$（换句话说，就是对不同的 $t$ 都有一个 condition $z$ 的条件分布），满足

\[p_0(\cdot \mid z) = p_{\text{init}}, \quad p_1 (\cdot \mid z) = \delta_z \quad \forall z \in \mathbb{R}^{d}\]

也就是说这个条件概率路径可以看作是分布上的一个轨迹，可以逐渐的把初始分布 $p_{\text{init}}$ 调整为一个单点分布 $\delta_z$. 下方的图，第一行就显示了一条条件概率路径：

从图里可以看到，如果对不同的条件概率路径做带权综合，可以设计一个初始分布和数据分布的分布插值。这个分布插值其实就是边际概率路径，就是考虑所有的 $z$ 之后的综合：

\[p_t(x) = \int_{z} p_t(x \mid z) p_{\text{data}} (z) dz\]

如果我们能够设计一个边际向量场，满足按这个向量场走之后，对每时刻 $t$ 都恰好符合分布 $p_t$，那么这个向量场就可以完成 $p_{\text{init}} \to p_{\text{data}}$ 的转化了。

条件 & 边际向量场

如果构造出了上面的一个条件概率路径，能不能构造一个对应的 ODE $u_t^{\text{target}} (\cdot \mid z)$, 满足若 $X_0$ 从初始分布中采样，则 $X_t$ 时刻服从条件概率路径在 $t$ 时刻的分布呢？也就是

\[X_0 \sim p_{\text {init }}, \quad \frac{\mathrm{d}}{\mathrm{~d} t} X_t=u_t^{\text {target }}\left(X_t \mid z\right) \quad \Rightarrow \quad X_t \sim p_t(\cdot \mid z) \quad(0 \leq t \leq 1) .\]

这个 ODE 完成的是 $p_{\text{init}} \to \delta_z$ 的转化，有什么用呢？事实上，借用下面的 边际化技巧，可以得到我们所需要的边际向量场和上面的条件向量场之间的关系：

边际化技巧：定义 \(u_t^{\text {target }}(x)=\int u_t^{\text {target }}(x \mid z) \frac{p_t(x \mid z) p_{\text {data }}(z)}{p_t(x)} \mathrm{d} z,\)，这个向量场满足 \(X_0 \sim p_{\text {init }}, \quad \frac{\mathrm{d}}{\mathrm{~d} t} X_t=u_t^{\operatorname{target}}\left(X_t\right) \quad \Rightarrow \quad X_t \sim p_t \quad(0 \leq t \leq 1) .\)

例：高斯形式推导

若 $p_{\text{init}} = \mathcal{N}(0, I_d)$，则对一个数据点 $z$, 可以构造 $p_t(\cdot \mid z): \mathcal{N}(\alpha_t z, \beta_t^2 I_d)$. 如果满足 $\alpha_0 = \beta_1 = 0, \alpha_1 = \beta_0 = 1$, 那么上述分布就满足 $p_0(\cdot \mid z) = \mathcal{N}(0, I_d), p_1(\cdot \mid z) = \mathcal{N}(z, 0) = \delta_z$，从而就是我们需要的条件概率路径。

有了上述条件概率路径后，下一步就是去试图构造 $u_t^{\text{target}}(x \mid z)$ 了. 这部分的逻辑是这样的：我们试图先构造出 $X_t = \psi_t(X_0 \mid z)$ 应当满足的形式，再对其关于 $t$ 求导，就可以求得向量场的形式了。瞪眼可得

\[\psi_t^{\text{target}}(x \mid z) = \alpha_t x + \beta_t z\]

该流恰好满足了在任何时刻 $t$, 随机变量 $X_t$ 都服从 $p_t^{\text{target}}(x \mid z)$. 因此说不定直接对这个形式求导，就可以得到 $u_t^{\text{target}}(x \mid z)$ 的形式：

[ \begin{aligned} & \frac{\mathrm{d}}{\mathrm{~d} t} \psi_t^{\text {target }}(x \mid z)=u_t^{\text {target }}\left(\psi_t^{\text {target }}(x \mid z) \mid z\right) \quad \text { for all } x, z \in \mathbb{R}^d
& \stackrel{(i)}{\Leftrightarrow} \quad \dot{\alpha}_t z+\dot{\beta}_t x=u_t^{\text {target }}\left(\alpha_t z+\beta_t x \mid z\right) \quad \text { for all } x, z \in \mathbb{R}^d
&\stackrel{(i i)}{\Leftrightarrow} \quad \dot{\alpha}_t z+\dot{\beta}_t\left(\frac{x-\alpha_t z}{\beta_t}\right)=u_t^{\text {target }}(x \mid z) \quad \text { for all } x, z \in \mathbb{R}^d
&\stackrel{(\mathrm{iiii})}{\Leftrightarrow} \quad\left(\dot{\alpha}_t-\frac{\dot{\beta}_t}{\beta_t} \alpha_t\right) z+\frac{\dot{\beta}_t}{\beta_t} x=u_t^{\mathrm{target}}(x \mid z) \quad \text { for all } x, z \in \mathbb{R}^d \end{aligned} ]

其中 $\dot{\alpha}_t = \partial_t \alpha_t, \dot{\beta}_t = \partial_t \beta_t$. 从而就得到了条件向量场：

\[u_t^{\text {target }}(x \mid z)=\left(\dot{\alpha}_t-\frac{\dot{\beta}_t}{\beta_t} \alpha_t\right) z+\frac{\dot{\beta}_t}{\beta_t} x\]

上面的推导中并没有用到 $p_{\text{data}}$ 的任何信息，而这个信息在定义边际概率路径与边际向量场中是必要的。

学习边际向量场

上面的推导告诉我们，事实上 $u_t^{\text{target}} (x)$ 是可以由条件向量场“加权平均”得到的。而 Flow Model 只包含 $u_t^{\theta}$ 的话，目标就是让 $u_t^{\theta} \approx u_t^{\text{target}}$. 可以定义损失函数为：

\begin{aligned} \mathcal{L}{\mathrm{FM}}(\theta) & =\mathbb{E}{t \sim \text { Unif }, x \sim p_t}\left[\left|u_t^\theta(x)-u_t^{\text {target }}(x)\right|^2\right]
& \stackrel{(i)}{=} \mathbb{E}{t \sim \text { Unif }, z \sim p{\text {data }}, x \sim p_t(\cdot \mid z)}\left[\left|u_t^\theta(x)-u_t^{\text {target }}(x)\right|^2\right], \end{aligned}

问题来了，$u_t^{\text{target}}(x)$ 是由一个积分定义的，不知道其具体的值怎么办？考虑下面这个形式的 loss, 对比上面的函数是把边际向量场替换为了条件向量场：

\[\mathcal{L}_{\mathrm{CFM}}(\theta)=\mathbb{E}_{t \sim \mathrm{Unif}, z \sim p_{\text {data }}, x \sim p_t(\cdot \mid z)}\left[\left\|u_t^\theta(x)-u_t^{\text {target }}(x \mid z)\right\|^2\right]\]

非常巧妙的是，上述两个损失函数的差其实是一个常数，从而二者梯度相等。这说明只要优化下式，就可以达成优化上式的目的。（证明略）

将上一节中我们得到的 $u_t$ 标准形式代入本节：

\begin{aligned} \mathcal{L}{\mathrm{CFM}}(\theta) & =\mathbb{E}{t \sim \mathrm{Unif}, z \sim p_{\mathrm{data}}, x \sim \mathcal{N}\left(\alpha_t z, \beta_t^2 I_d\right)}\left[\left|u_t^\theta(x)-\left(\dot{\alpha}t-\frac{\dot{\beta}_t}{\beta_t} \alpha_t\right) z-\frac{\dot{\beta}_t}{\beta_t} x\right|^2\right]
& \stackrel{(i)}{=} \mathbb{E}{t \sim \mathrm{Unif}, z \sim p_{\mathrm{data}}, \epsilon \sim \mathcal{N}\left(0, I_d\right)}\left[\left|u_t^\theta\left(\alpha_t z+\beta_t \epsilon\right)-\left(\dot{\alpha}_t z+\dot{\beta}_t \epsilon\right)\right|^2\right] \end{aligned}

考虑若 $\alpha_t = t, \beta_t = 1 - t$ 则 $\dot{\alpha}_t = 1, \dot{\beta}_t = -1$, 得到的损失函数形式其实就是 Rectified Flow:

\[\mathcal{L}_{\mathrm{cfm}}(\theta)=\mathbb{E}_{t \sim \mathrm{Unif}, z \sim p_{\text {data }}, \epsilon \sim \mathcal{N}\left(0, I_d\right)}\left[\left\|u_t^\theta(t z+(1-t) \epsilon)-(z-\epsilon)\right\|^2\right]\]

本章总结

流匹配的目的是学习边际向量场。为此，

  • 首先定义了条件概率路径和其对应的条件向量场，从概率路径得到向量场是现实的，并且有封闭形式；
  • 随后，可以通过条件向量场积分得到边际向量场的形式。
  • 最后由两个 loss 之间的相互转化，可以发现学习条件向量场 $\approx$ 学习边际向量场，这样就可以写出算法了。
